# さくさくSRT

動画を見ながら字幕（SRT）のつなぎ目・タイミングを手早く編集できる、軽量な単一 HTML ツール。
Premiere Pro の自動書き起こし SRT の手直しを主な用途に想定しています。

**公開版:** https://onihachi.github.io/sakusaku-srt/

## 特長

- **単一 HTML ファイル / 依存ゼロ**。ブラウザで開くだけ、インストール不要・オフライン動作
- 動画・字幕はブラウザ内で読み込むだけで、どこにもアップロードされません
- Premiere Pro の「書き起こしを書き出し」テキスト（`00;00;00;14 - ...` 形式・話者行入り）と標準 SRT の両方を自動判別で読み込み
- 書き出しは常に標準 SRT

## 主な操作

- 動画（MP4）と SRT/テキストをドラッグ&ドロップで読み込み
- 隣接ブロックの **結合**（行間の「⇧ 結合」ボタン）
- **分割**: テキストをクリックして位置を決め、`Cmd/Ctrl+Enter`（または `T` キー・分割ボタン）
- タイミング調整: 「⏱始を今に」「⏱終を今に」、下部バーの ±0.5s
- タイムライン: ホイールで拡大縮小、黄色い再生バーをドラッグでスクラブ
- **保存**（`Cmd/Ctrl+S`）: 元ファイルへ直接上書き（Chrome/Edge 系）。非対応ブラウザではダウンロード

## キーボード

| キー | 動作 |
| --- | --- |
| Space | 再生 / 停止 |
| ← / → | ∓0.5 秒（Shift で ∓5 秒） |
| , / . | 1 フレーム（1/30 秒）単位 |
| ↑ / ↓ | 前後のブロックへ移動 |
| T | アクティブな字幕を分割 |
| Cmd/Ctrl+Enter | カーソル位置で分割（入力中も可） |
| Cmd/Ctrl+Z / Shift+Z | 元に戻す / やり直し |
| Cmd/Ctrl+S | 保存 |
